ChromHandler is built for chromatography workflows where the goal is not just to inspect one chromatogram, but to organize whole experiments, process batches of runs, quantify peaks, and turn the result into analysis-ready kinetic data.

## 📦 Installation

Install ChromHandler from PyPI:

```bash
pip install chromhandler
```

For the latest development version, install directly from GitHub:

```bash
pip install git+https://github.com/FAIRChemistry/Chromhandler.git
```

## ⚡ Quick Start

```python
from chromhandler.handler import Handler

handler = Handler.read("data/reaction_series", mode="timecourse")

sample = handler.samples[0]
chrom = sample.chromatograms[0]

print(sample.id)
print(chrom.id)
print(chrom.reaction_time)
print(len(chrom.peaks))
```

This shows the core idea behind ChromHandler:

- load a whole directory of chromatograms in one step
- preserve the sample and time-course structure
- start working immediately with chromatograms, peaks, and reaction times
